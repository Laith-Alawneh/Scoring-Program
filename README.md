---

### 📋 About The Project

**Tournament Scoring System** is a desktop application built with Python and Tkinter for managing tournament competitions. It allows you to register teams and individual participants, create events, record scores, and automatically calculate rankings based on a point system.

* 🎯 **Team Management**: Register up to 4 teams with up to 5 members each
* 👤 **Individual Participants**: Register up to 20 individual competitors
* 🎪 **Event Management**: Create team-based or individual events across different categories
* 📊 **Score Recording**: Record scores for participants in various events
* 🏅 **Automatic Ranking**: Calculate and display leaderboard based on ranking points
* 📈 **Real-time Statistics**: View current tournament statistics and event results

### 🚀 Usage

1. **Register Teams**: Start by registering tournament teams
2. **Add Players**: Add players to registered teams
3. **Register Individuals**: Register individual participants (if applicable)
4. **Create Events**: Create events (team-based or individual) in different categories
5. **Record Scores**: Record scores for participants in each event
6. **View Results**: Check event results and overall leaderboard

### 🎯 System Constraints

- Maximum **4 teams** per tournament
- Maximum **5 players** per team
- Maximum **20 individual** participants
- Maximum **5 events** per participant

---

### 📊 Point System

The ranking system awards points based on final position:
- 🥇 **1st Place**: 100 points
- 🥈 **2nd Place**: 80 points
- 🥉 **3rd Place**: 60 points
- **4th Place**: 40 points
- **5th Place**: 20 points
- **Other positions**: 10 points (default)
